### Notes on method

- For 10-fold CV, all feature scaling and SMOTE take place within each training fold to prevent leakage.
- The 30% test portion is never used to choose model parameters.
- Silhouette is undefined for k = 1; although the question specifies k in {1,...,50}, the valid silhouette candidates start at 2. Candidate clusterings are trained on all records; only score computation uses a 500-observation sample for runtime control.
- In this exercise, the Hamming score is the per-position fraction correct, `1 - hamming_loss`. Some multi-label literature uses another definition (set-based Jaccard score); our convention is declared and used consistently.
- SMOTE raises each class below 25% of the current majority to that floor, rather than forcibly equalizing all classes. This is a deliberate, reproducible treatment of imbalance.
